Project / 项目

《算法同桌》
ALGORITHM DESKMATE
一份关于 AI、学习与人的数字田野报告。

发起与制作：第七排观察组
项目周期：2025.09—2026.11.12
地点：某市 · 校园与南园社区
版本：v1.0

“第七排观察组”为作品署名，非真实机构。请在上传或提交前替换为你的真实姓名 / 小组名称。

Data / 数据说明

重要：本作品中的数据为构造样本。

问卷比例、使用频率、访谈引语、30 天日志条目与社区前后测数据，均为展示网页结构与交互而设计，并非真实调研结果。人物均为化名，部分情节为典型化处理。

方法框架、伦理清单与工具箱可以直接复用。替换为真实数据前，请先取得受访者同意，并删除所有可识别信息。

Visual / 视觉

全站未使用外部图片。数据图形、抽象声音肖像、星图、图标与纹理均由 CSS、内联 SVG 和 Canvas 生成。

字体：使用系统字体（MiSans / 苹方 / 微软雅黑 / Bahnschrift / 等宽字体），不加载外部字体文件。

配色：深空墨、信号青、荧光黄绿与警示橙。

References / 参考与致谢

感谢 16 位接受访谈的同学、老师、家长与社区居民，以及 312 位问卷填写者。感谢英语、数学与信息技术教研组提供的讨论空间。

方法上受 UNESCO AI 素养框架、OECD 教育研究、参与式行动研究与批判性数据素养的启发。完整阅读清单见 开放资源。

以上致谢同样属于演示文本，人物与机构为化名。

Tech & Accessibility / 技术与无障碍

纯静态网站，无框架、无构建依赖、无后端。全站可在本地打开；留言与测试结果只保存在浏览器中。

支持键盘导航、可见焦点、减少动态效果偏好、语义化标题与 ARIA 标签。正文在 1024px 及以上屏幕保持双栏阅读，移动端自动单栏。
