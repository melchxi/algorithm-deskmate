# AI 内容核查清单
# 算法同桌 / ALGORITHM DESKMATE
# 可打印 · 可改写 · CC BY-NC-SA 4.0

在使用 AI 提供的信息做决定、写作业或转发之前，停一下，逐条确认：

[ ] 1. 这条信息最早出现在哪里？我能找到原始页面吗？
[ ] 2. 文件名、作者、DOI、数据是否可以在独立来源中检索到？
[ ] 3. 它是否把相关性说成了因果，或把个案说成了普遍规律？
[ ] 4. 它是否在利用恐惧、愤怒、紧迫感推动我立刻行动？
[ ] 5. 是否涉及转账、验证码、身份证号、健康或家庭隐私？
[ ] 6. 我是否因为“它说得很顺”而跳过了核查？
[ ] 7. 如果我错了，最坏的结果是什么？谁还能帮我确认？

三步动作：
① 找原始发布者 → ② 找到原文 / 原数据 → ③ 检查时间、范围与适用条件 → 再做决定。

记住：找不到来源，本身就是一条重要信息。
