PROMPT LAB / 13

你怎样问，
决定它怎样答。

“帮我改作文”和“请指出我这篇作文里最弱的一处论证，不要重写，只问我三个问题”——这是两个完全不同的请求。提示词不是咒语，它是在告诉对方：你要扮演谁、做什么、不要做什么。

STRONG PROMPT / 强提示specific protocol
你是一位高中历史老师。下面是我对“辛亥革命”材料题的答案，请不要直接重写。先指出我答案中的一个史实错误和一个论证漏洞，然后每次只问我一个问题，引导我自己修改。最后用三行总结我的薄弱点。 我的答案： [粘贴答案] 材料： [粘贴材料]
变化：明确角色、提供上下文、限制输出方式、把最终修改权留给自己。
WHAT CHANGED / 01从“帮我判断”变成“帮我看见自己的判断”。
WHAT CHANGED / 02AI 从答案生产器变成了追问者。
WHAT CHANGED / 03仍然需要你核对史实与材料边界。
NOT A MAGIC TRICK 强提示不会消除幻觉，也不会保证更好的成绩。它只是让协作更具体，让你更容易发现输出中哪一部分需要检查。提示词的好坏，要看它是否帮助你保留了自己的判断。

01 / CONTEXT

给上下文

材料、年级、已有答案，越具体越不容易得到泛泛而谈。

02 / CONSTRAINT

给限制

告诉它不要做什么，往往比告诉它要做什么更有效。

03 / TRACE

要过程

要求暴露推理步骤，才有机会发现它在哪一步走偏。

04 / OWNERSHIP

留决定权

让它提问、给选项，但最后的判断与署名仍然属于你。

FIELD NOTE / 一次失败

我写了一段“完美提示词”，然后得到了一个更自信的错误。

在设计这个实验室时，我用一段非常详细的提示词让 AI 解释一道物理题。我规定了角色、受众、步骤、语气，甚至要求它“标注每一步的依据”。它照做了，每一步都写得很清楚。

但它在一个关键公式的适用条件上错了。格式越完整，我越晚发现。那一刻我才明白：提示词能改善协作，但不能替代核查。它让错误变得更难被发现，有时甚至更危险。

所以这个页面没有“最佳提示词模板”。只有一组可以反复修改的动作：给上下文、设限制、要过程、自己核对。

LOG / 2025.10.30
我的提示词请严格按步骤解释，每一步都标注依据，不要省略任何推导。
结果：回答结构完美，依据部分有一条伪造的定理名称。提示词没有让它更真实，只让它更有说服力。核查仍然发生在我这一侧。
